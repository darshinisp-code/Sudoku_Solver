# Sudoku Solver
A Python-based Sudoku Solver that uses the Backtracking Algorithm to solve Sudoku puzzles efficiently.

## Features
- Solves Sudoku puzzles automatically
- Validates number placement
- Uses Backtracking Algorithm
- Fast and accurate solution generation

## Technologies Used
- Python
- HTML

## How to Run
1. Download the project files.
2. Open the project in Python.
3. Run the main Python file.
4. Enter the Sudoku puzzle and get the solution.
